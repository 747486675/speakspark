# SpeakSpark

**临场应变，脱口而出。**

SpeakSpark 是一个用随机话题和倒计时帮助你练习口头表达的网页应用。选择练习模式和话题分类，抽取一个题目，然后在限定时间内组织观点、举例并完成演讲。适合个人即兴表达训练、英语口语练习，以及课堂或小组中的限时分享。

项目使用 Vue 3、TypeScript 和 Vite 构建，是一个纯前端单页应用。当前无需账号、后端服务或 API Key；设置和题库数据保存在当前浏览器中。

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 即兴开讲 | 抽题后直接进入演讲倒计时，练习快速组织语言 |
| 深度准备 | 先准备，再手动开始演讲；可为题目添加参考网址 |
| 分类题库 | 包含生活、文学、历史、理财、创业、科技、健身等中英文话题 |
| 随机抽题 | 通过滚动动画展示抽题过程，优先避开最近抽到的 5 个题目；没有其他候选时回退到完整题库 |
| 可调计时 | 设置演讲和准备时长，支持暂停、继续、重新开始和提前结束 |
| 题库管理 | 按模式和分类添加、删除条目，深度准备条目支持可选参考网址；当前限制见下文 |
| 本地保存 | 保存时长、静音设置、题库条目和最近抽题记录 |
| 提示与适配 | 提供抽题及计时结束音效、最后 10 秒视觉提醒、移动端布局和减少动画适配 |

“深度准备 / Deep Research”是先查资料再演讲的练习模式，资料由使用者自行查阅。当前项目没有接入 AI 研究、录音、语音识别或演讲评分功能。

## 快速开始

### 环境要求

- Node.js 20 或更高版本及 npm。
- 支持现代 JavaScript、Local Storage 和 Web Audio 的浏览器。

项目没有在 `package.json` 中声明 `engines`。当前依赖中，Vite 5 的 Node.js 要求为 `^18.0.0 || >=20.0.0`，jsdom 24 要求 Node.js 18 及以上。使用 Node.js 20 及以上可同时满足这些要求；Node.js 14 无法运行当前工具链。

### 安装与启动

在项目根目录执行：

```bash
npm ci
npm run dev
```

如果终端已经位于 `speakspark` 目录，直接从 `npm ci` 开始。项目包含 `package-lock.json`，`npm ci` 按锁文件安装依赖。

打开终端中 Vite 输出的本地地址，通常是 `http://localhost:5173`；端口被占用时，以终端输出为准。

需要让同一局域网内的手机访问时：

```bash
npm run dev -- --host 0.0.0.0
```

在手机浏览器中打开终端显示的 Network 地址，电脑和手机需在同一局域网中。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动 Vite 开发服务器 |
| `npm run build` | 先运行 Vue / TypeScript 类型检查，再生成 `dist/` |
| `npm run preview` | 本地预览已构建的 `dist/`，需先执行构建 |
| `npm test` | 运行 Vitest 测试 |
| `npm run lint` | 使用 ESLint 检查 TypeScript 和 Vue 文件 |

## 使用方法

### 即兴开讲

1. 选择 **即兴开讲**。
2. 选择一个话题分类。
3. 点击 **抽题**，等待题目落定。
4. 点击 **开始计时**，围绕题目进行演讲。
5. 时间到后关闭计时窗口，继续抽取下一题；也可以提前点击 **完成演讲**。

页面初始显示的题目只是预览。完成一次抽题后，“开始计时”按钮才会启用。抽题或计时期间，模式、分类、题库和设置入口会锁定。

### 深度准备

1. 选择 **深度准备**，抽取一个研究话题。
2. 点击 **开始计时**，进入准备阶段。
3. 查阅资料、整理观点。如果题目配置了参考网址，可以在准备或待演讲阶段点击 **打开参考网址**。
4. 准备时间结束，或提前点击 **我准备好了**，进入待演讲状态。
5. 点击 **开始演讲**，启动演讲倒计时。

准备结束后不会自动开始演讲，可以确认准备就绪后再开始。

### 设置与计时操作

点击 **⚙ 设置** 可调整：

| 设置 | 默认值 | 可调范围 | 快捷预设 |
| --- | --- | --- | --- |
| 演讲时长 | 1 分钟 | 1–10 分钟 | 1、3、5、10 分钟 |
| 准备时长 | 10 分钟 | 1–60 分钟 | 5、10、15、30 分钟 |
| 提示音 | 开启 | 开启 / 静音 | — |

计时窗口支持：

- **暂停 / 继续**：暂停或恢复当前阶段。
- **重新开始**：重置当前阶段的倒计时。
- **我准备好了 / 完成演讲**：提前结束当前阶段。
- **结束本次训练**：退出计时窗口，保留当前选中的题目。
- **空格键**：在计时窗口内暂停或继续准备 / 演讲倒计时。
- **Esc**：关闭计时窗口；设置和题库弹窗也支持 Esc 关闭。

### 管理题库

点击 **📚 题库入口** 打开“自定义题目”，选择模式和分类后添加条目。深度准备模式可以填写参考网址；网址支持 HTTP / HTTPS，未填写协议时会尝试补全 `https://`。内置题目的参考网址默认为空。

初次使用时，题库管理列表会载入内置条目；新增内容保存在当前浏览器。题库归一化时，每个即兴分类和深度准备列表最多保留 100 条，标题按忽略大小写的方式去重。

当前抽题会再次合并源代码中的内置题目，因此在管理界面删除内置条目后，它仍可能被抽到。自定义题目的最终落点也存在接入问题，详见“当前限制与已知问题”。

### 表达练习建议

宽屏页面侧栏提供“表达三步法”：

1. 先用一句话说清核心观点。
2. 给出两个理由或一个具体例子。
3. 最后回到观点，做一个简短总结。

## 内置话题

题库定义在 `src/data/topics.ts`，包含 14 个即兴分类和 1 个深度准备题库：

| 类型 | 内容 |
| --- | --- |
| 即兴分类 | 综合、世界名著、中国名著、世界史、中国史、Personal finance、Entrepreneurship、Startups、Tech / AI、Fitness、Nutrition、Productivity、History、Literature |
| 深度准备 | 心理学效应、认知偏差、博弈论、概率悖论、经济学和社会现象等 |

题目包含中文和英文，可以选择自己希望练习的语言进行表达。修改内置分类、名称或题目时，编辑 `src/data/topics.ts`；浏览器内的题库操作只影响当前浏览器的数据。

## 数据保存

应用使用 `localStorage` 保存以下内容，键名前缀沿用 `unprompted:`：

| 键名 | 内容 |
| --- | --- |
| `unprompted:speech` | 演讲时长，单位为秒 |
| `unprompted:research` | 准备时长，单位为秒 |
| `unprompted:muted` | 是否静音 |
| `unprompted:library` | 按模式和分类保存的题库，当前格式版本为 2 |
| `unprompted:recent` | 最近抽到的题目，最多 5 条 |

这些数据保存在当前浏览器、当前站点来源下，不会自动同步到其他设备。更换浏览器、访问不同端口或清除站点数据后，原有设置和自定义题目不会随之迁移。应用目前没有提供题库导入或导出界面。

模式、当前分类、当前选题和进行中的倒计时没有持久化，刷新页面后会重新开始。浏览器存储不可用时，应用仍尝试运行，但设置和题库修改无法保证保存。

需要恢复初始状态时，可在浏览器开发者工具中删除本项目的上述 5 个存储键，再刷新页面；操作前请自行备份需要保留的自定义题目。

### 常见修改入口

- **名称和文案**：修改 `src/config.ts`；浏览器标题与描述需同步修改 `index.html`。
- **内置分类和题目**：修改 `src/data/topics.ts`。
- **时长范围、默认值和最近记录数量**：修改 `src/composables/usePersistentSettings.ts`；快捷预设在 `SettingsDialog.vue` 中。
- **配色和布局**：修改 `src/styles/globals.css` 及组件内样式。
- **抽题动画参数**：修改 `src/lib/spin.ts`。

## 构建与静态部署

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`，可以将该目录交给静态网站服务托管，无需额外启动业务后端。`npm run preview` 用于本地检查构建结果。

当前 Vite 配置使用默认的根路径。如果部署到 `/speakspark/` 等子路径，需要在 `vite.config.ts` 中将 `base` 配置为对应路径后重新构建。

## 当前限制与已知问题

以下问题来自当前代码检查，功能描述应结合这些限制理解：

1. **删除内置题目未完全影响抽题池**：`getActiveTopics()` 会重新合并 `topics.ts` 中的内置题目，因此管理列表中的删除操作不能保证将内置题目从抽题池移除。
2. **自定义题目的落点处理尚未统一**：`ActionBar.vue` 从合并后的题库抽题，而 `usePracticeMachine.ts` 落定时只校验内置题库；`App.vue` 的 `onSettle()` 也没有转交落点参数。抽中仅存在于自定义题库的题目时，最终展示可能与预选结果不一致。
3. **新增失败的提示接入有缺口**：题库弹窗尝试读取事件 `emit()` 的布尔返回值，但父组件的处理结果不会通过 Vue 事件返回。重复标题或无效网址可能被数据层拒绝，却没有在弹窗中得到相应反馈。
4. **验证范围有限**：现有测试覆盖工具函数、状态机、倒计时和设置弹窗；尚无完整页面的端到端测试，上述题库界面与抽题流程的连接未被现有测试覆盖。
